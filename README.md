**SPOTIFY ALBUM TRENDS – POWER BI DASHBOARD**

**Project Overview**

This project focuses on exploring and analyzing Spotify album data using Microsoft Power BI. The dashboard presents music-related data through interactive visualizations to make trends and patterns easier to understand.

**Tools & Technologies**

- Microsoft Power BI
- Power Query
- Data Cleaning and Transformation
- Data Visualization

**Project Objectives**

- Explore and understand Spotify album data.
- Analyze album-related trends and patterns.
- Transform and organize data using Power Query.
- Build interactive dashboards using Power BI.
- Present data insights through clear visualizations.
